# Creative Brief

## Audience And Destination

Developers evaluating Schema Stream on the docs homepage and GitHub README. The primary output is a
silent 16:9 website video; the same timeline must survive as a compact looping GIF.

## Expanded Prompt

Create a polished product sequence that demonstrates behavior, not marketing claims. Begin inside a
dark JSON surface where provider chunks extend a schema-shaped object while a blue scan line marks
progress. Transition into a split operational view where completed paths move from code into an
event ledger and trigger a real conditional decision. Then show the same stream under four snapshot
policies, making cadence differences visible through discrete pulses and counts. Finish by
materializing the release-readiness dashboard from sparse placeholders into metrics, milestones,
owners, and the final ship recommendation. Use the exact Schema Stream docs palette and embedded
Geist typography. The result should feel authored, technical, and calm, with enough foreground
metadata to reward repeat viewing.

## Rhythm

`precise-build / event-hit / cadence-compare / resolved-hold`

## Message

Typed JSON becomes usable incrementally, and application code can react at the exact boundaries it
cares about.
